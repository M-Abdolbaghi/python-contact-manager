# Python Contact Manager

A simple command-line contact management application built with Python and SQLite.

## Features

- Add new contacts
- Show all contacts
- Search contacts by name
- Update contact information
- Delete contacts

## Technologies

- Python
- SQLite
- SQL

## How to Run

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/python-contact-manager.git
```

Go to the project directory:

```bash
cd python-contact-manager
```

Run the application:

```bash
python main.py
```

## Application Menu

```text
===== Contact Manager =====

1. Add contact
2. Show contacts
3. Search contact
4. Update contact
5. Delete contact
6. Exit
```

## Database

The application uses SQLite to store contact information.

Each contact contains:

- ID
- Name
- Phone
- Number
